## A page, not a control panel

This turns off the parts of the window built for programmers: the line numbers,
the little map on the right, the file tabs, the warnings, and the pop-up
suggestions.

It also switches to a serif typeface at a comfortable size and wraps your lines
at a readable width.

If you ever want the ordinary view back, there is a **Restore the normal VS Code
look** option that puts every single setting back exactly as it was.

### One question you may be asked

The first time your writing folder opens, VS Code may ask whether you trust the
authors of the files in it. You made this folder yourself, so choose **Yes, I
trust it**. Saying no leaves VS Code in a careful mode where it will not change
any settings, and the writing look cannot be turned on. Your writing still opens
and still saves itself.
